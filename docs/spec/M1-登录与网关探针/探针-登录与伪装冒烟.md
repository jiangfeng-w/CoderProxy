# 探针：登录 + 工具容忍度复现（等价 M1，今日实测可行）

> 目的：M1 探针当时只把结论写进总计划 §3.4，**可运行脚本未存档**。下面这份是自包含、可直接跑的复现。结论一句话：**牛码网关高容错——任意工具名都不拒绝（标准 function calling，校验 schema 不校验名字），relay 长尾默认透传。**

这份脚本走**银海通 IM 静默登录**（M1 实测成功路径，无 DB、无浏览器），纯 `httpx`。若本机无银海通（`localhost:13631` 不通），需降级浏览器 PKCE——参考实现仓库的 `server/app/auth/ta3/oauth.py` 与 `callback.py`（要 DB 会话 + 回调 server，较繁，一般用不上）。

## 前置（本机独有坑，务必照做）
- `python -m pip install --target <本地目录> httpx`（本机全局 `python` 缺 venv，无 httpx）。
- **一切请求必须 `trust_env=False`**：本机 httpx 默认读系统代理，会把 `lc.yinhaiyun.com` 走隧道 → 连不上。
- 聊天用**模型自带 `llm-` key**（不是 oauth 会话 token）。

> 本项目 relay 实现前，本脚本临时 `sys.path` 引 参考实现 的 `server` 包跑即可；M2 落地后提升为 `relay/scripts/login_smoke.py` 并入 git。

## 脚本

```python
import asyncio, sys, json
import httpx

API_BASE = "https://lc.yinhaiyun.com/newcoder"
UA = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
      "(KHTML, like Gecko) ta3-new-coder-desktop/1.0.0 Chrome/125.0.0.0 "
      "Safari/537.36 Electron/31.0.0")
# 跑本脚本可临时：sys.path.insert(0, r"D:\Code\home\github-project\参考实现\server")

CLIENT = httpx.AsyncClient(timeout=30.0, trust_env=False)  # <-- 关键：直连

async def im_login():
    """对应 参考实现 oauth.py try_im_login：银海通 :13631/getuid → aiContinueLogin"""
    r = await CLIENT.get("http://localhost:13631/getuid")     # trust_env=False
    uid = r.json()["data"]["uid"]
    r2 = await CLIENT.post(f"{API_BASE}/aiContinueLogin",
                           headers={"Authorization": uid}, content=b"")
    return r2.json()["data"]["authToken"]

async def list_assistants(_token):
    r = await CLIENT.post(f"{API_BASE}/ai/continue/ide/list-assistants?appId=personal",
                          headers=_hdr(_token), content=b"")
    return r.json()  # 直接是数组，item 含 id/name/model

def _hdr(t):
    return {"User-Agent": UA, "X-Call-Source": "APP",
            "Authorization": f"Bearer {t}", "api-key": t, "x-api-key": t}

def _chat(token, model, messages, tools=None):
    body = {"model": model, "messages": messages, "stream": True,
            "stream_options": {"include_usage": True}, "tool_stream": True}
    if tools:
        body["tools"] = [{"type": "tool", "name": n,
                          "description": d or "do it",
                          "input_schema": {"type": "object", "properties": {}}} 
                         for n, d in tools]
        body["tool_choice"] = "auto"
    return CLIENT.post(f"{API_BASE}/v1/messages", headers=_hdr(token), json=body)

async def main():
    token = await im_login()
    print("[ok] IM 登录, token 头8位:", token[:8])
    asst = await list_assistants(token)
    model = asst[0]["model"]  # M1 用 glm-5.3-flash；以目录实时返回为准
    print("[ok] 目录返回 model:", model)

    base_msg = [{"role": "user", "content": "只回复 ok"}]
    probes = [
        ("原生工具 Bash",            [("Bash", "run a shell command")]),
        ("未知工具 glob_file_search", [("glob_file_search", "find a file")]),  # 长尾透传关键
        ("无工具",                    None),
    ]
    for name, tools in probes:
        async with await _chat(token, model, base_msg, tools) as r:
            lines = [l for l in r.text.splitlines() if l.startswith("data:")]
            print(f"\n== {name} ==  status={r.status_code} data行数={len(lines)}")
            print("  head:", (lines[0][:160] if lines else "") or r.text[:160])
    await CLIENT.aclose()

if __name__ == "__main__":
    asyncio.run(main())
```

## M1 实测记录（据此脚本曾跑出的三条基线）
| 探针 | 结果 | 说明 |
|---|---|---|
| `Bash`（原生） | 200，模型真返回 `tool_call` | 验证「登录 + llm-key + 工具调用」整链路通 |
| `glob_file_search`（未知） | 200，正常应答、未拒 | **牛码不校验工具名 → 长尾可透传** |
| 无工具 | 200，回 "ok"（带 reasoning_content） | 普适调用可用 |
| 目录端点 | 裸数组（非对象包一层） | 真身是 POST `list-assistants?appId=personal`，org 的 GET 404/418 |
| IM 登录 | source=im 秒登 | 本机有银海通；PKCE 作兜底可用 |
