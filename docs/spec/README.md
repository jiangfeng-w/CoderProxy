# 开发需求文档总览

本目录存放 CoderProxy 的全部开发需求文档，**一个需求一个子目录，子目录内一篇需求 + 该期支撑脚本/文档**。需求**按名字命名，不再按序号递增**（临时插入需求不再需要改动其它需求的编号）；进度在下面「需求列表」里跟踪状态。方案细节以根目录 `CoderProxy-开发计划-2026-09-03.md` 为准，本目录只放单篇需求/实现的落地口径。

> 注：① 本项目**无竞品项目分析**（区别于 Bing Rewards 的 `docs/Bing Rewards 赛道竞品分析.md`）。需求来源 = 开发计划的调研结论 + M1 探针实测证据。② 历史需求（M1–M10）沿用 `M<序号>-<名>` 目录名便于追溯；**新需求一律用需求名**建子目录，不编序号。
