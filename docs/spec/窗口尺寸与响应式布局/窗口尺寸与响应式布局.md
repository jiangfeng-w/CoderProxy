# 窗口尺寸与响应式布局

> **状态**：方案已定稿（2026-10-17；用户拍板：默认/最小宽高拉大 + 宽度缩小时布局重排）
> **优先级**：交付（全局 UI 基建，日志页/统计页重构的前置约束）
> **来源**：2026-10-17 用户需求——「软件默认宽高和最小宽高要拉大；当宽度缩小时，要对布局重新调整」。
> **依赖**：M4 Tauri 壳与 GUI、`Shell.vue` 布局、日志页重构、统计页重构
> **定稿日期**：2026-10-17

## 1. 背景与目标

当前窗口配置：

| 配置 | 现值 |
|---|---|
| `width` / `height` | 960 × 680 |
| `minWidth` / `minHeight` | 800 × 600 |
| 侧栏 | 固定 180px |
| 响应式 | 仅 Overview 有一个 `max-width:1200px` 断点；其余页面基本无重排 |

问题：

- 日志/统计表格列多，960px 宽度下必须横向滚动，信息密度低；
- 窗口缩到 800px 时侧栏、顶栏、筛选栏、表格互相挤压；
- 各页面自行写布局，断点不统一；
- 图表、抽屉、弹窗在窄宽度下可能溢出；
- 没有统一的“宽/中/窄”布局模式。

### 目标

| # | 功能 | 说明 |
|---|---|---|
| F1 | 窗口尺寸 | 默认 **1280 × 800**，最小 **1024 × 700**（两个配置文件同步） |
| F2 | 断点体系 | 统一 wide / medium / narrow 三档，全应用共用 |
| F3 | Shell 响应式 | 窄屏侧栏收为 64px 图标 rail；顶栏操作区自动收缩/换行 |
| F4 | 页面重排 | Overview/Config/Providers/Logs/Stats 的网格、筛选栏、表格、卡片按断点重排 |
| F5 | 图表自适应 | ECharts 容器 `ResizeObserver` + `resize()`；热力图/趋势图不溢出 |
| F6 | 弹窗/抽屉 | 宽度用 `min(92vw, …)`；窄屏全宽；底部按钮换行 |
| F7 | 验收 | 在 1280×800 / 1100×720 / 1024×700 三档手测无页面级横向滚动、无重叠 |

### 非目标

- ❌ 不做手机/平板布局（最小宽度 1024，低于此不允许缩放）。
- ❌ 不做窗口尺寸记忆（跨重启保持上次大小）——后续可单独立项。
- ❌ 不改业务逻辑/接口。
- ❌ 不做主题切换/暗亮色重做。

## 2. 窗口尺寸

### 2.1 目标值

| 配置 | 目标值 | 说明 |
|---|---|---|
| `width` | **1280** | 比现值 +320px，容纳日志/统计默认列 |
| `height` | **800** | 比现值 +120px，减少纵向滚动 |
| `minWidth` | **1024** | 低于此不进入窄屏布局，直接禁止缩放 |
| `minHeight` | **700** | 保证筛选栏 + 表格 + 分页可用 |
| `center` | `true` | 首次启动居中；不改变现有窗口行为 |

> 若目标机器主要是 1366×768，可在实现时增加 Rust 启动 clamp：窗口尺寸不超过当前显示器工作区的 90%（宽/高分别 clamp，最小不低于 `minWidth/minHeight`）。此 clamp 为可选增强，不阻塞本 spec。

### 2.2 配置文件

必须同步修改：

- `src-tauri/tauri.conf.json`（release）
- `src-tauri/tauri.dev.conf.json`（dev overlay）

两处 `width/height/minWidth/minHeight` 保持一致，避免 dev 与安装版布局验收口径不同。

## 3. 断点体系

| 模式 | 宽度 | 布局 |
|---|---|---|
| **Wide** | ≥ 1280px | 侧栏 200px + 文字标签；内容 padding 20px；KPI 4 列；表格默认列全开 |
| **Medium** | 1100–1279px | 侧栏 180px；内容 padding 16px；顶栏间距收紧；隐藏端口文字；KPI 4 列或 2 列（按页面）；表格隐藏低优先级列 |
| **Narrow** | 1024–1099px | 侧栏 64px 图标 rail（悬浮 tooltip 显示名称）；内容 padding 12px；顶栏 48px；KPI 2 列；筛选栏换行；表格横向滚动；抽屉/弹窗全宽 |

实现约定：

- 断点常量集中在 `frontend/src/styles/responsive.css`（或 `style.css` 顶部注释），页面只用同一组 `@media`：
  - `@media (max-width: 1279px)` → medium/narrow 共用
  - `@media (max-width: 1099px)` → narrow
- 不允许各页面再自造 1200/900/768 等断点；Overview 现有 1200 断点改为 1279，统一口径。
- 布局优先用 CSS Grid/Flex + `minmax()`/`auto-fit`，减少硬编码宽度。

## 4. Shell 响应式

### 4.1 结构

优先用 Naive UI 布局组件重构（规则 7）：

- `NLayout`（外层）
- `NLayoutHeader`（顶栏，52px / narrow 48px）
- `NLayoutSider`（侧栏，`width=200`、`collapsed-width=64`、`collapse-mode="width"`）
- `NLayoutContent`（内容区，`min-width:0; overflow:auto`）

若重构风险大，保留现有 `.app/.topbar/.body/.sidebar/.content` 结构，但必须实现同等断点行为。

### 4.2 侧栏

| 模式 | 行为 |
|---|---|
| Wide | 200px，图标 + 文字；版本号显示 |
| Medium | 180px，图标 + 文字；版本号缩小 |
| Narrow | 64px，仅图标；`NTooltip` 显示页面名；版本号隐藏 |

- 窄屏图标居中，`nav-item` padding 收窄，active 左边框保留。
- 自动收起，不要求手动切换；如后续加手动切换，需持久化用户选择（本期不做）。

### 4.3 顶栏

- Wide：品牌 + 状态 + 端口 + 重启按钮。
- Medium：隐藏端口文字（保留 tooltip）；`gap` 24→16。
- Narrow：隐藏端口；品牌名可保留；状态只显示圆点 + “运行中/已停止”；重启按钮文案缩为“重启”或图标按钮。
- 操作区 `flex-wrap: wrap`，不允许把状态挤出窗口；必要时把低频操作收进 `NDropdown`。

### 4.4 内容区

- `min-width: 0`，避免 flex 子项撑破；
- 页面级滚动由 `.content` 承担；
- 页面内部表格/代码块自己横向滚动，**不允许整页横向滚动**；
- 内容 padding：20 / 16 / 12px。

## 5. 页面级重排

| 页面 | Wide | Medium | Narrow |
|---|---|---|---|
| **Overview** | 双列卡片、KPI 2×2 | 双列 → 单列（≤1279） | 单列；KPI 2 列；图表高度 300→240 |
| **Config** | 表单双列/行内布局 | 行内标签可换行 | 标签上置、控件全宽；卡片单列 |
| **Providers** | 标签页横排、账号卡 `minmax(560px,1fr)` | 账号卡 `minmax(420px,1fr)`；操作按钮换行 | 标签页横向滚动；账号卡单列；模型表横向滚动；弹窗 92vw |
| **Logs** | 默认列全开；筛选单行 | 隐藏低优先级列（账号/客户端/重试）；筛选换行 | 只保留核心列（时间/状态/请求ID/模型/耗时/Token/错误）；表格横向滚动；详情抽屉 100% 宽；筛选折叠到“更多筛选” |
| **Stats** | KPI 4 列；趋势图 300px；热力图全宽 | KPI 2 列；趋势图 260px；筛选换行 | KPI 2 列；趋势图 240px；热力图横向滚动；页签横向滚动；表格横向滚动 |

### 5.1 日志页

- 筛选栏：`flex-wrap: wrap`；窄屏把低频筛选项收进 `NPopover`（更多筛选）。
- 表格：外层 `overflow-x:auto`；`NDataTable` 设置 `scroll-x`；核心列固定最小宽度。
- 详情抽屉：`width: min(880px, 92vw)`；narrow 下 `width: 100vw`。
- 代码块（原始错误）：`max-height: 40vh; overflow:auto; white-space:pre-wrap; word-break:break-all`。
- 分页：窄屏换行，页码器允许收缩。

### 5.2 统计页

- KPI：`grid-template-columns: repeat(4,1fr)` → `repeat(2,1fr)`；窄屏卡片高度压缩。
- 趋势图：容器宽度 100%，高度 300/260/240；`ResizeObserver` 触发 `chart.resize()`。
- 热力图：外层 `overflow-x:auto`；格子保持可读最小尺寸，不强行压缩。
- 页签：`NTabs` 设置 `tabs-padding` 或外层横向滚动，避免挤出。
- 表格：横向滚动；窄屏隐藏低优先级指标列（如 cached/reasoning/retry）。

### 5.3 供应商页

- 标签页：`NTabs` 外层 `overflow-x:auto`；窄屏可滚动。
- 账号卡片网格：`repeat(auto-fill, minmax(560px, 1fr))` → `minmax(420px,1fr)` → 单列。
- 操作按钮组：`flex-wrap: wrap`；窄屏主按钮全宽或两列。
- 弹窗：`width: min(560px, 92vw)`；表格弹窗 `min(900px, 94vw)`。

### 5.4 配置页

- 表单行：`display:flex; flex-wrap:wrap`；窄屏 label 上置、控件 `width:100%`。
- 卡片：单列；长路径/密钥使用 `word-break:break-all`。
- 保存/重置按钮组：窄屏换行，主按钮靠右或全宽。

## 6. 图表与弹窗

### 6.1 ECharts

- 每个图表容器挂 `ResizeObserver`，回调 `chart.resize()`；组件卸载时 `disconnect()`。
- 窗口尺寸变化时，图表宽度跟随容器；不允许固定 `width: 900px`。
- 趋势图/热力图/分布图统一高度档位：300 / 260 / 240。
- 图表 tooltip 设置 `confine: true`，避免窄屏溢出窗口。

### 6.2 弹窗/抽屉

- `NModal` / `NDrawer` 宽度统一 `min(<design-width>, 92vw)`；narrow 下可 100vw。
- 底部按钮 `flex-wrap: wrap`；主操作按钮不被裁切。
- 表格型弹窗内部横向滚动，不撑破 modal。

## 7. 全局 CSS 约定

```css
html, body, #app { width: 100%; height: 100%; }
*, *::before, *::after { box-sizing: border-box; }
.content, .page, .card { min-width: 0; }
.long-text { overflow-wrap: anywhere; word-break: break-word; }
.table-scroll { overflow-x: auto; }
```

- 禁止在页面根节点设置固定 `width` 或 `min-width`（除非是表格单元格）。
- 长模型名/错误消息使用 `overflow-wrap:anywhere` 或 `text-overflow:ellipsis` + tooltip。
- 页面根容器 `width:100%`，不出现横向滚动条。

## 8. 已知边界 / 风险

- **最小宽度 1024**：低于此不提供布局；用户无法把窗口缩到手机宽度。
- **默认 1280×800 可能高于 1366×768 工作区**：可选 Rust 启动 clamp；若不做，OS 可能把窗口底部放到屏幕外，验收时需在目标机器确认。
- **超长模型名/错误体**：表格/代码块仍需横向滚动或换行，不能保证一屏全显。
- **图表 resize 频率**：ResizeObserver 可能高频触发，需节流（`requestAnimationFrame`）。
- **弹窗宽度**：Naive UI 的 preset card 有自身 max-width，需在窄屏显式覆盖。
- **窗口尺寸不持久化**：每次启动回到默认值；如需记忆，后续单独立项。
- **dev/release 一致性**：两个 Tauri 配置必须同步，否则验收口径不同。
