# 打包与分发（M5）

- **状态**：已实现（2026-09-03）

- **优先级**：交付

- **来源**：开发计划 §4 架构；M4 的 sidecar 运行时需求

- **定稿日期**：2026-09-03

## 需求背景

M4 桌面壳要在最终形态里免用户装 Python 直接跑，需要把 Python relay 及其依赖、vendored ta3 库一起打进分发包。

## 设计方案（落地）

1. **sidecar 打包**：Python relay 用 **PyInstaller onefile** 打成单文件 exe（`relay/relay-onefile.spec`），
   关键 hiddenimports：`relay.routes`（uvicorn 字符串式路由解析）、`sqlite3`、`uvicorn.*`、`h11`、`pydantic`。
   构建脚本：[`relay/build_sidecar.py`](../../../relay/build_sidecar.py)，产物拷贝为 `src-tauri/binaries/relay-sidecar-x86_64-pc-windows-msvc.exe`。
2. **分发产物**：

   - Windows 安装包：`CoderProxy_0.1.0_x64-setup.exe`（Tauri NSIS，中英双语）。

   - 便携包：`CoderProxy_0.1.0_portable.zip`（release exe + sidecar，解压即用；需系统自带 WebView2）。

   - sidecar 通过 Tauri `externalBin` 集成，构建时自动拷为 `relay-sidecar.exe` 与主程序同目录；`lib.rs` 用 `shell().sidecar("relay-sidecar")` spawn。
3. **运行时数据目录**：`lib.rs` 用 `app.path().app_data_dir()` 传给 sidecar（`RELAY_DATA_DIR`），打包后不依赖相对路径。
4. **孤儿进程治理**：PyInstaller onefile 是「bootloader 父 + 实际 relay 子」两层结构，`tauri-plugin-shell` 的 `kill()` 只杀直子进程（实测会残留 uvicorn 占端口）。`lib.rs` 用 Windows **Job Object（KILL\_ON\_JOB\_CLOSE）** 回收进程树：ready 后**枚举 bootloader 的全部子孙进程逐个 assign**（只 assign 父进程不会追溯已存在的子进程——这是首版修复残留的根因），正常退出显式关句柄、强杀/崩溃由内核关句柄自动兜底。实测子进程完全启动后强制杀桌面进程，sidecar 整树全灭（连续 3 次）。
5. **升级**：牛码契约变更需重打包 sidecar 并同步版本；Tauri updater 未启用（调研结论：公网分发再补签名+updater）。
6. **签名**：Windows 代码签名未做（可选，公网分发推荐）。
7. **单实例**：`tauri-plugin-single-instance` 全局互斥，二次启动直接聚焦已有主窗口（show + unminimize + focus），不重复开进程、不重复起 sidecar。实测第二实例退出、仅留原实例。
8. **合规门禁**：Overview 页顶部常驻警示条（封号风险 + 小号验证提示），见开发计划 §10 风险 1。

## 调研结论（记录的决策点）

- **PyInstaller onefile 可行**：产物自包含，`relay/m5_nopython_test.py` 剥离 PATH 中 python 后运行，1.67s 内就绪。

- **Tauri bundler 此版本不支持** **`portable`** **目标**：合法 targets 仅 deb/rpm/appimage/msi/nsis/app/dmg；便携以「release exe + sidecar 手动 zip」实现。

- **externalBin 工作正常**：构建产物里 `relay-sidecar.exe` 与主程序同目录，Tauri 自动补 `x86_64-pc-windows-msvc` 后缀。

- **onedir vs onefile**：默认 onefile（交付体积小、单文件好分发）；onedir（`relay/relay.spec`）留作排障，`build_sidecar.py --keep-ondir` 可选构建。

## 已知边界

- PyInstaller onefile 首次启动需临时解包，耗时略增；库冲突按 ta3 依赖裁剪（当前 hiddenimports 已覆盖运行路径）。

- 牛码契约（端点/UA/目录结构）变更会连带影响打包物，需版本对齐与回归。

- 便携 zip 依赖系统 WebView2 Runtime（Win11 预装，Win10 需安装）；安装包模式可自动引导安装 WebView2。

- 未做代码签名，公网分发时 SmartScreen/杀软可能告警。
