# 供应商页（登录与多平台账号入口）

> 状态：规划中（2026-10-07 立项）
> 优先级：核心（多平台账号聚合的 UI 承载体；WorkBuddy 前端账号页的挂接点）
> 来源：用户决策（2026-10-07）——侧边栏底部登录（[M10 §6](../M10-设置页与侧边栏登录/M10-设置页与侧边栏登录.md)）废弃；侧边栏新增「供应商」页统一承载登录与账号管理，对标 9router 的「提供商」页形态（本地克隆 `d:\Code\ref-projects\9router`，dashboard/providers）
> 依赖：M9 服务开关（顶栏服务语义保留）；WorkBuddy多账号登录与签到（`/v1/platforms/*` 账号 API 已定稿，本页是其前端挂接点）
> 定稿日期：—

## 1. 背景与目标

### 背景

- 登录入口演进：顶栏登录（M4–M9，main 现状）→ 侧边栏底部用户区（M10 §6，2026-09-04 曾在工作区实现，随清理入 stash `12f5bb21` **未进 main**）。
- WorkBuddy 立项后账号形态质变：单账号「当前用户」→ **多平台多账号池**（牛码单账号 + WorkBuddy 任意数量账号 + Trae/Qoder 扩展位）。「侧边栏头像 = 当前用户」的形态承载不了「每平台若干账号、各有各的状态」。
- 用户拍板（2026-10-07）：不恢复 M10 §6；侧边栏加「供应商」页，登录等账号操作收进去。

### 目标

| # | 功能 | 说明 |
|---|---|---|
| F1 | 供应商页 | 侧边栏新增「供应商」导航项；页内按平台分节展示上游账号 |
| F2 | 牛码卡片 | ta3 作为第一张供应商卡片：登录（IM 静默优先/PKCE 兜底）、账号名、退出、同步模型目录（复用 `/v1/auth/*`） |
| F3 | WorkBuddy 分节 | 多账号卡片（昵称/配额/签到状态/连签天数）+ 添加/删除/签到/配额刷新——即 WorkBuddy spec 实施步骤 6 的 UI，挂接到本页而非独立导航项 |
| F4 | 状态可见 | 每卡片显示账号/连接状态（借鉴 9router：「无连接 / Error 429 · 27m ago」式）；支持「全部测试/全部签到」类批量动作 |
| F5 | 扩展位 | Trae/Qoder 接入时新增分节零改主干（`GET /v1/platforms` 注册表驱动，对齐 PlatformAdapter） |

### 非目标

- ❌ 模型白名单/连通性测试（Models.vue 职责不动）。
- ❌ 设置类条目（思考兜底开关、数据目录归设置/M10 数据目录）。
- ❌ 改服务门控逻辑（`_serving() = 已登录 && 未手动停`，relay 侧不变）。
- ❌ 9router 的 combo 编排/代理池等高级形态（归「WorkBuddy聊天反代与多平台聚合」远景）。

## 2. 设计方案（概要，待定稿）

### 2.1 信息架构

```
侧边栏导航: 概览 | 模型 | 日志 | 统计 | 供应商 | 配置
                                    └─ 新增
供应商页:
├─ 牛码（Ta+3）卡片: 登录/账号/退出/同步目录（/v1/auth/*）
├─ WorkBuddy 分节: 账号卡片网格 + 添加账号 + 批量签到（/v1/platforms/workbuddy/*）
└─ (扩展位) Trae/Qoder: 平台接入后按 /v1/platforms 注册表自动出现
```

### 2.2 顶栏与门控分工

- 顶栏**只保留「服务」语义**：运行状态/端口/停止重启（M9）。main 顶栏现存的登录按钮随本需求移除（M10 §6 原方案的「顶栏去登录态」由本页实现）。
- 门控文案保留：未登录时顶栏「未登录 · 登录后自动启动服务」，点击跳转供应商页。

### 2.3 前端结构（初拟）

- `frontend/src/views/Providers.vue`（新）：平台分节 + 卡片网格。
- WorkBuddy 账号卡片区组件化（`stores/workbuddy.ts` 已在 WorkBuddy spec 规划），作为本页分节挂入。
- `Shell.vue`：views 注册表 + 导航项 + 顶栏去登录按钮。

### 2.4 被否决的备选

- **侧边栏底部用户区（M10 §6）**：单账号形态产物，装不下多账号池；已废弃（stash `12f5bb21` 不恢复，设计细节留档于 M10 §6）。
- **每平台独立导航项（牛码页 / WorkBuddy 页 …）**：平台增多后侧边栏膨胀、与 9router 心智不符；采纳单一「供应商」页 + 分节。

## 3. 已知边界

- 牛码 IM 静默登录依赖本机银海通（`:13631`），卡片需对降级 PKCE 浏览器路径给出提示。
- 批量动作沿用现有频控约束（顺序串行、登录后每会话一次摸底；冒烟只用小号——AGENTS 硬性规则 5）。
- 卡片连接状态的「真实请求反哺」依赖同名需求落地；本页首版先显示显式测试结果。
